#  Vault Tracker

An intuitive **Expense Tracker** that helps you manage your **expenses, goals, and budgets** with just a few clicks.  
Built with a modern full-stack architecture to deliver a smooth, responsive, and secure experience.

> ⏸️ **Project Status:** Development is currently on hold due to overengineering complexity.  
> The next phase will focus on simplifying the architecture and improving maintainability.


## 🚀 Features

- 📊 **Expense Management** — Track daily, weekly, or monthly expenses effortlessly.  
- 🎯 **Goal Setting** — Create and monitor personal saving goals.  
- 💵 **Budget Planning** — Define budgets and get real-time insights into your spending.  
- 📈 **Data Visualization** — Understand your spending habits through clean and interactive UI.  
- 🔐 **Secure Backend** — Built with a robust Python backend and GraphQL API.  
- ⚡ **Responsive Design** — Works seamlessly across devices with Tailwind CSS and Shadcn UI.  



## 🛠️ Tech Stack

**Frontend:**  
- [Next.js](https://nextjs.org/) — React framework for optimized performance and routing  
- [React](https://react.dev/) — UI component library  
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS framework  
- [Shadcn/UI](https://ui.shadcn.com/) — Beautiful, accessible UI components  

**Backend:**  
- [Python](https://www.python.org/) — For server-side logic and API handling  
- [GraphQL](https://graphql.org/) — Flexible and efficient data querying  

**Database:**  
- [PostgreSQL](https://www.postgresql.org/) — Reliable, open-source relational database
